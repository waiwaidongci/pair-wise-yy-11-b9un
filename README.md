# hxyfront-62010 潜水气瓶充填记录

源提示词编号：5

我想做一个给潜水店使用的气瓶充填前端系统，工作人员可以记录气瓶编号、容积、检验有效期、残压、目标压力、氧含量、氦含量、充填方式和操作员。页面需要有待充填队列、混合气比例提示、气瓶检验过期提醒、充填完成签收和单个气瓶历史记录。

## 夜班充填排程（当前版本）

外岛潜店夜潜车队 06:00 出海，前台仅剩一张临时高压储气组使用卡。夜班登记瓶号、限时（领瓶时点）、目标混合气与瓶阀螺纹后：

- 按领瓶时点（夜班时间轴 18:00 起算、跨零点顺延）排出唯一充填位；
- 同一预约单内瓶号重录当场挡住，并标黄指出原行；
- 储气组余压不足（<210bar）时保留限时、改排备用气源，已锁定的使用卡不被挤掉；
- 检验过期瓶不进队列，留送检区；
- 使用卡的锁定 / 释放 / 改排全部留档（卡片存档）。

### 业务文件

| 文件 | 职责 |
| --- | --- |
| `src/gasPlanner.ts` | 配气判断：混合气比例校验与提示、过期判定、充填位排序、余压核算与备用气源改排 |
| `src/cardStore.ts` | 卡片存档：使用卡流转留档、预约单与队列的 localStorage 持久化 |
| `src/App.tsx` | 值班界面：预约单登记、充填队列、送检区、存档日志 |
| `src/types.ts` | 共享领域类型 |
