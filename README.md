# hxyfront-62010 潜水气瓶充填记录

源提示词编号：5

我想做一个给潜水店使用的气瓶充填前端系统，工作人员可以记录气瓶编号、容积、检验有效期、残压、目标压力、氧含量、氦含量、充填方式和操作员。页面需要有待充填队列、混合气比例提示、气瓶检验过期提醒、充填完成签收和单个气瓶历史记录。

## 技术栈

React + Vite + TypeScript

## 业务文件

- `src/gasPlanner.ts` — 配气判断：分压配气步骤（氦→纯氧→空气）、瓶阀螺纹校验（超耐压 / 富氧禁 YOKE）、储气组余压与可用气量核算
- `src/cardArchive.ts` — 卡片存档：预约单登记与瓶号查重（重录挡住并指出原行）、按领瓶时点排唯一充填位、临时储气组卡登记即锁定（余压不足保留限时改排备用气源，不挤掉已锁定卡片）、检验过期瓶留送检区、localStorage 持久化与归档快照
- `src/DutyBoard.tsx` — 值班界面：夜班登记台、充填位队列、储气组卡面板、送检区、06:00 出海倒计时

## 本地运行

```bash
npm install
npm run dev
```
